# 參考商店 B：Gumroad 組合包拆解（內部筆記，2026-09-26）

> 內部學習用，不在任何公開內容中點名或評論此賣家。

## 公開頁面數字
- 商店只有 4 個商品和 1 個組合包，全部 0 則評價；頁面沒有公開銷售數字。
- 組合包 US$12.49，內含 3 個商品，單買合計 6 + 2.49 + 19.99 = US$28.48。
- 使用 Gumroad 內建的 Bundle 功能：組合包頁面會自動列出內含商品和各自的單價。
- 封面是直式 1024×1536（2:3）。
- 說明很短：一句話承諾、What’s Included 三行、Perfect For 七種人。

## 值得學
1. **Gumroad 內建 Bundle**：頁面會顯示單買總價，買家一眼就看到省了多少。
2. **直式封面**：手機上占的畫面比橫式大。
3. **「Perfect For」清單**：短、好掃讀。

## 不要學
- 標題用收入數字（「$10K」）：屬於收入暗示，跟 CheckMaybe 不做收入承諾的規則衝突（FTC 相關內容見 Resell 第 8 頁）。
- 同一商品重複上架兩次、價格不同：買家會困惑。
- 主題太雜：Threads 接案、AI SaaS、數位產品。
- 說明太短，沒有頁數、內容明細、退款或免責說明。

## 套用到 CheckMaybe（待創辦人決定）
- 做「CheckMaybe Complete Toolkit Bundle」：Sell + Use + Resell（單買 3 × US$15 = US$45），組合價建議 US$29–35。
- 組合包封面和之後的新商品封面，加一版直式 2:3。
- 說明加一段簡短的「Perfect for」。
