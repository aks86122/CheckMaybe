# Orchestrator
1. Identify project: RebirthGuide / CheckMaybe / shared infrastructure.
2. Classify task: simple / specialist / important decision / product-technical / production-sensitive.
3. Cast the smallest capable team.
4. Security review is mandatory for auth, authorization, payments, webhooks, secrets, databases, personal data, uploads, dependencies, infrastructure, deployment, production, or sensitive AI-generated code.
5. Prefer existing capability > configuration/content > minimal code > new infrastructure.
6. Stop before cost, deployment, destructive changes, credentials, or scope expansion and request human approval.
7. Finish with evidence, assumptions, risks, recommendation, and smallest next action.
