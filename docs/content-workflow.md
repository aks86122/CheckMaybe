# Claude寫貼文的6個固定步驟（三個品牌共用）

創辦人2026-10-17：參考一篇「AI指令抄作業」輪播，要Claude自己做到裡面的6件事。
這份是重生引路人repo的版本；副業實驗室、CheckMaybe的repo裡有同樣的一份（讀者換成各自品牌的）。
品牌規則（V7、j-voice、中文排版）永遠優先；這6步是寫稿流程，不是新規則。

## 1. 拆爆款：學骨架，不抄句子
J給別人的爆款截圖時，先拆：開頭鉤子、段落結構、情緒轉折、行動呼籲。再用同樣骨架寫自己品牌的版本，不沿用原文句子。
拆的結果寫在草稿最上面（「骨架來源」一行），讓J知道學的是哪一篇。

## 2. 從留言、私訊挖題目
J給留言或私訊截圖時：相似問題分組、依次數排序，每組寫成一個題目，用讀者自己的話。
重生引路人可以用私訊個案表「互動紀錄」裡的問題挖題，但只取問題類型，不寫任何個案資料、名字、帳號、金額。

## 3. 一篇多平台
每篇定稿都附：Threads主文（＋串文）、IG caption、FB版、限時動態1張（含提問或投票）。重點一樣，寫法不一樣；不加原文沒有的數字。

## 4. 交稿前，先過3個毒舌讀者
每篇交給J之前，Claude先扮演3個讀者讀一遍：會在哪一句滑走、哪裡不信、哪裡看不懂。改完再交，草稿最後附一行結果（例：「讀者檢查：家屬在第2行可能滑走，已把結論提前」）。

| 品牌 | 3個讀者 |
| --- | --- |
| 重生引路人 | 正在欠債、很怕被說教的人；擔心家人欠債的家屬；第一次看到、懷疑又是賣課的人 |
| 副業實驗室 | 還在觀望的上班族；試過副業沒賺到的人；第一次看到、覺得又在賣課的人 |
| CheckMaybe | someone already on 2–3 pay-later plans; a skeptic who thinks "budget tips" are obvious; a first-time viewer scrolling fast |

## 5. Reels／口播一律附提詞卡
寫影片腳本時同時給提詞卡：每行12字內、用[畫面]標每段要拍什麼、最有價值那句後面標「停格截圖」。語氣像聊天，不像上課。寫完再過一次第4步。

## 6. 蹭時事，但要連得上
J要時事題時，Claude用網頁搜尋找最近7天台灣（CheckMaybe：美國）討論度高的話題，挑能自然連到品牌主題的；連不上就跳過。
每個話題給：一句說出讀者心裡話的開頭、品牌觀點、結尾一個讓人想留言的問題。
不蹭：災難、悲劇、有人過世、個人隱私八卦。時事裡的數字要附來源。
