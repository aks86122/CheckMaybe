# J AI Agency v1.1
Portable low-cost multi-agent operating pack for RebirthGuide and CheckMaybe.

## Rules
- Keep full capability available; activate the minimum team needed.
- Simple task: 1 agent.
- Important decision: max 2 specialists (+ Reality Checker if justified).
- Product/funnel/technical decision: max 3 specialists.
- Code: Engineering + QA (Evidence Collector).
- Auth/payments/DB/API/secrets/uploads/production: Engineering + Security + QA + human approval.
- Load exactly one project context unless explicitly comparing projects.
- Never deploy, publish, create paid infrastructure, change production data, or expose credentials without explicit approval.
