# Gumroad

Files used only on Gumroad. Images shared with other storefronts (cover, preview, featured) stay in `../images/`.

| File | Use |
| --- | --- |
| `thumbnails/can-i-sell-this-gumroad-thumb.png` | Square product thumbnail, 1200×1200 (Gumroad minimum 600×600) |
| `thumbnails/can-i-use-this-gumroad-thumb.png` | Square product thumbnail, 1200×1200 |
| `can-i-sell-this-gumroad-fields.md` | Additional details, Button text and Custom message for Can I Sell This? |
| `can-i-use-this-gumroad-fields.md` | Additional details, Button text and Custom message for Can I Use This? |

Every new product gets its own `<slug>-gumroad-fields.md` (see `templates/toolkit-product-template.md`, step 7).
