Search a listing photo by its address

Marketplaces remove file data, so for a listing photo the best check is a reverse image search. The same photo on a stock site, a wholesale site or another shop is a warning sign. Right-click the listing photo, copy the image address and paste it here.

Search TinEyeSearch Google LensSearch Bing

These open the search site in a new tab and send it the image address. No address yet? The buttons open each site, where you can upload a photo yourself.

What this check can and can't tell you

File data can be removed or changed by apps, so missing AI markers do not prove a photo is not AI-made, and camera data does not prove a photo was never edited. Content Credentials are checked with the official C2PA library; signer names are shown as written on the certificate and are not checked against a trust list. Platforms also use their own detection, so this check cannot predict whether a photo will be labeled or a listing removed.
